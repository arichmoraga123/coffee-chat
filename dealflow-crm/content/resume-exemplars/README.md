# Resume exemplars

Strong, de-identified resumes the reviewer uses to calibrate each class year. Optional.

- Put 2–3 per level in `freshman/`, `sophomore/`, `junior/`, `senior/` as `.txt` or `.md` (paste the resume text).
- Remove names, emails, phone numbers and LinkedIn URLs first. The loader also strips emails, phones and LinkedIn URLs as a safety net.
- Only the first 3 files per folder (alphabetical) are used.
